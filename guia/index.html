Veja a cota real e nunca perca o fio no /clear

Statusline que mostra contexto, cota de 5 h, semanal geral e semanal por modelo. Três skills que fecham o ciclo: checkpoint, auditoria de memória e handoff.

Começar o guia Ver no GitHub
O que é

Três peças que se conversam

O modelo não enxerga a própria cota. A barra enxerga. As skills usam o que a barra mostra pra decidir quando compactar, auditar ou entregar a sessão pro próximo agente.

📊 Statusline com cota real

Lê o endpoint oficial de uso e mostra ctx, 5h, w (semanal geral) e F (semanal do modelo em uso, com ! em alerta). Cache de 300 s pra não martelar a API.

🧩 Skills de sessão

session-statusline (checkpoint), memory-audit (o que manter, comprimir, apagar) e session-handoff (resumo pro próximo agente). Todas chat-only, sem inventar estado.

🗺️ Plano de otimização

Gatilhos lidos direto da barra: ctx 40/60/80 %, cota de 5 h, cota por modelo. Regras de higiene e o que medir pra saber se está funcionando.

Como funciona

O ciclo de uma sessão

A barra sobe, você faz um checkpoint. Ficou ruidoso, audita e compacta. Vai limpar, entrega o handoff e cola na sessão nova.

trabalhar→ ctx sobe→ checkpoint→ memory-audit→ /compact→ handoff→ /clear
1

Checkpoint

Foto rápida: foco atual, o que ficou guardado × candidato a memória, próximos passos e uma recomendação (continuar, compactar, auditar, handoff).

2

Auditoria de memória

Inventário do contexto e do CLAUDE.md. Classifica cada item em manter, comprimir, mover ou apagar. Só grava se você pedir.

3

Handoff

Resumo estruturado com caminhos absolutos, processos em background, comandos de verificação e um "pegue daqui". Sem retrospectiva.

Pré-requisitos

O que precisa estar na máquina

Tudo local. O script lê o token OAuth do próprio Claude Code e só fala com o endpoint oficial de uso.

Claude Code logado

Login via claude.ai (OAuth). O token fica em ~/.claude/.credentials.json.

claude # e /login se ainda não estiver

jq + curl

O script depende dos dois pra ler o payload e chamar a API.

sudo apt install jq curl

O repo

Clone e cole os prompts, ou copie os arquivos na mão.

git clone https://github.com/inematds/claude-session-kit.git
Guia de uso · passo a passo

Do clone à barra funcionando

Cada passo tem o comando real. Se preferir, os prompts do repo fazem isso por você dentro de uma sessão do Claude Code.

1

Instale o script da statusline

Copie o script pra pasta do Claude Code e dê permissão de execução.

cp statusline/statusline-command.sh ~/.claude/statusline-command.sh
chmod +x ~/.claude/statusline-command.sh
2

Aponte o settings.json pro script

Mescle o bloco abaixo no seu ~/.claude/settings.json (não apague as outras chaves). Ou cole statusline/PROMPT.md numa sessão e deixe o Claude fazer.

{
  "statusLine": { "type": "command", "command": "bash ~/.claude/statusline-command.sh" }
}
3

Teste a renderização

Rode o script com um payload mínimo e confira a linha.

echo '{"cwd":"'$PWD'","model":{"display_name":"Fable 5.1"}}' | bash ~/.claude/statusline-command.sh
# user@host:~/proj Fable 5.1  ctx 41%  5h:2%→19:10  w:69% F:80%!→14/09 21:00  d:40.9M
4

Leia a barra

Cada campo tem um significado e um gatilho no plano.

ctx 41%          # % da janela de contexto usada nesta sessão
5h:2%→19:10      # cota de 5 horas e a hora local do reset
w:69%            # cota semanal de todos os modelos (weekly_all)
F:80%!           # cota semanal do modelo em uso (weekly_scoped) — "!" = alerta
→14/09 21:00     # quando a semanal reseta
d:40.9M          # tokens do dia, contados nos JSONL locais
5

Instale as três skills

Copie as pastas pra ~/.claude/skills/, ou cole skills/PROMPT-instalar.md numa sessão.

cp -r skills/session-statusline skills/memory-audit skills/session-handoff ~/.claude/skills/
ls ~/.claude/skills | grep -E 'session|memory'
6

Use o ciclo

Diga estas frases dentro da sessão. Cada uma dispara a skill certa.

checkpoint            # ou "onde estamos" → session-statusline
analise a memória     # ou "memória inchada" → memory-audit
handoff               # ou "vou dar /clear" → session-handoff, depois /clear e cole o resumo
Exemplos

Gatilhos lidos da barra

Do PLANO-OTIMIZACAO.md. A barra é o sensor; a tabela é a regra.

ctx 40–60 %

checkpoint. Decide se compacta agora ou segue.

ctx > 60 % ou saída repetitiva

memory-audit → aplicar o plano de enxugamento → /compact.

ctx > 80 %

handoff → /clear → colar o handoff na sessão nova.

F: com "!"

Trocar de modelo pra tarefas mecânicas (/model) ou esperar o reset indicado na barra.
